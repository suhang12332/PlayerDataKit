# PlayerDataKit

`PlayerDataKit` 是一个 Swift Package，用于读取 **Minecraft Java 版** 存档数据，并在 SwiftUI 中展示“全部玩家 × 全部游戏实例”的统计结果。

它面向启动器或管理工具场景，支持从多个实例目录扫描 `saves`，按玩家聚合统计，并提供可直接嵌入的图表化 UI 组件。

## 使用范围说明（仅为主项目维护）

此项目仅为主项目维护，仅用于服务主项目业务（主项目：`Swift Craft Launcher`）。

主项目仓库：<https://github.com/suhang12332/Swift-Craft-Launcher>

- 不承诺通用化场景兼容（功能与 API 以主项目需求为准）
- 不提供对外稳定版本承诺（可能在迭代中发生调整）
- 不提供公开技术支持或第三方接入保障
- 不接受以第三方通用接入为目标的兼容性诉求

## 特性

- 扫描多个游戏实例，自动收集存在 `saves` 的目录
- 按玩家 UUID 聚合统计（游玩时长、死亡、击杀、进度、移动距离等）
- 解析 `stats/*.json`、`advancements/*.json` 与 `level.dat`（NBT + gzip）
- 提供完整的 SwiftUI 统计面板（含筛选器、排行榜、占比图、热度图等）
- 支持玩家名/头像映射注入，便于与启动器账户系统集成
- 内置中英文（默认 `zh-Hans`）本地化文案能力
